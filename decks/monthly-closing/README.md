# 월결산 자동화 및 연결 경영실적 보고 (경영진 보고용)

`build.js`로 `.pptx`를 생성한다. 총 14슬라이드.

## 실행

```bash
npm install pptxgenjs
node build.js 월결산_자동화_경영진보고.pptx
```

## 구성

| # | 슬라이드 |
|---|---|
| 1 | 표지 |
| 2 | Executive Summary — KPI 4종 + 핵심 메시지 3 |
| 3 | As-Is 현행 결산의 병목 5가지 |
| 4 | To-Be 자동화 6단계 파이프라인 |
| 5 | 데이터 소스 맵 — 더존위하고(iCUBE) 10종 표준자료 |
| 6 | 결산 캘린더 D+8 → D+3 |
| 7 | 테크온(한국) 별도 손익계산서 |

| 9 | 연결조정분개 4단계 |
| 10 | 연결손익계산서 (각사 / 단순합산 / 연결조정 / 연결) |

## 데이터 기준

- 계정 체계와 위하고 메뉴 경로는 **「더존위하고(iCUBE) 자료제출양식 v1.0」**(Google Drive)을 따른다.
  해당 양식은 빈 템플릿이므로 실적 수치는 포함되어 있지 않다.
- 따라서 슬라이드의 **금액은 전부 구조 확인용 샘플**이다. 실제 연결정산표를 연동할 때는
  `build.js` 상단 근처의 표·차트 데이터 배열만 교체하면 된다.
- 연결 수치는 자체 정합성을 유지하도록 구성했다:
  단순합산 순이익 532 − 지분법이익 취소 117 − 미실현손익 28 = 연결 순이익 387.

## QA

```bash
python scripts/office/validate.py 월결산_자동화_경영진보고.pptx   # pptx 스킬 스크립트
soffice --headless --convert-to pdf 월결산_자동화_경영진보고.pptx
```

렌더링에는 `libreoffice-impress`와 `poppler-utils`가 필요하다.
